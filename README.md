# 🔧 Assistant IT Pro

**Assistant de dépannage informatique** avec plus de 500 diagnostics prêts à l'emploi.  
Idéal pour les techniciens support N1/N2.

## 🚀 Fonctionnalités

- 🔍 Moteur de recherche intelligent sur 500+ pannes.
- 👤 Système d'authentification sécurisé (mots de passe hashés avec bcrypt).
- 📊 Gestion des abonnements (Gratuit, Pro, Business).
- 💳 Paiement par virement bancaire.
- 📄 Export des résultats en PDF et Word (pour les offres Pro/Business).
- 🔒 Sécurisé avec variables d'environnement (ou secrets Streamlit).
